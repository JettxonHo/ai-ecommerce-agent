# DEC-005：MVP 采用最低可运行输入与增强输入分层

## Type

Product

## Status

Accepted

## Decision

AI Ecommerce Agent 的 MVP 输入采用分层设计：

1. 最低可运行输入；
2. 推荐增强输入；
3. 可选扩展输入。

系统必须能够在用户仅提供最低可运行输入时，完成基础的商品定位分析并生成营销 Brief。

缺少推荐输入或可选输入时，系统可以：

- 降低部分分析结论的置信度；
- 明确标记依据不足；
- 向用户提出补充资料建议；
- 减少无法可靠生成的内容。

但**不得**因为缺少评论、竞品或行业资料而完全阻断基础流程。

## Minimum Viable Inputs

MVP 的最低可运行输入包括：

- 商品名称；
- 商品品类；
- 商品功能、参数或文字说明；
- 价格或价格区间；
- 商家当前认为的主要卖点；
- 商品图片或其他商品展示资料；
- 本次推广目标。

其中，「商品图片或其他商品展示资料」表示：

- 用户可以提交图片；
- 也可以提交足以描述商品的文字资料。

> 图片是否是技术层面的强制字段，仍需在交互与多模态能力设计时进一步确认。

## Recommended Inputs

推荐用户补充：

- 用户评论；
- 用户调研资料；
- 常见用户问题；
- 当前商品详情页；
- 已有营销内容；
- 品牌定位或品牌资料。

这些资料用于增强：

- 用户需求分析；
- 购买动机分析；
- 购买阻碍分析；
- 卖点验证；
- 品牌一致性；
- 内容策略判断。

## Optional Inputs

用户还可以选择提供：

- 竞品资料；
- 行业报告；
- 平台案例；
- 运营知识文档；
- 历史推广结果；
- 其他能够支持商品定位和营销决策的资料。

这些资料**不属于** MVP 基础运行的必要条件。

## Input-Layer Principle

高层输入逻辑为：

```
最低可运行输入
商品基础资料 + 推广目标
        ↓
生成基础商品定位与营销 Brief
```

增强逻辑为：

```
最低可运行输入
+
评论 / 品牌 / 已有内容 / 竞品 / 行业资料
        ↓
提高分析深度、依据完整性和结果可信度
```

## Missing-Information Behavior

当输入资料不足时，产品**不得假装拥有不存在的信息**。

系统应区分：

- 用户明确提供的事实；
- 从资料中提取的事实；
- 基于证据形成的推断；
- 因资料不足而无法判断的事项；
- 需要用户补充的信息。

系统后续应具备某种输入完整性检查机制，但**具体实现形式尚未确定**。可能的表现包括：

- 缺失字段提示；
- 资料完整度说明；
- 补充问题；
- 分析置信度；
- 输出中的证据不足标记。

> 以上表现形式均**尚未确定**，不得在本次归档中写成完整功能规格。

## Reason

如果评论、竞品、行业报告或完整品牌资料被设为必填，MVP 将面临以下问题：

- 用户很难一次准备所有资料；
- Demo 对数据完整度依赖过高；
- 作品集演示容易被阻断；
- 小型商家可能本身缺乏结构化数据；
- 系统无法体现对信息不完整场景的适应能力。

同时，如果系统只接收极少量商品信息，又可能导致分析结果缺乏依据。因此采用分层输入：

- 用最低输入保证产品可以运行；
- 用增强输入提高分析质量；
- 用缺失信息提示保持结果诚实和可追溯。

## Impact

该决定将影响：

- 产品输入流程；
- PRD；
- MVP Scope；
- User Flow；
- 表单或资料上传设计；
- 商品资料的数据结构；
- 输入完整性检查；
- 用户补充问题机制；
- Agent 状态设计；
- RAG 和外部检索的使用边界；
- 输出中的事实、推断和置信度标记；
- 项目 Demo 数据准备；
- 验收标准。

后续所有输入字段都需要回答：该字段是基础流程必须使用，还是只用于提高结果质量？

## Decision Boundary

**本决定已经确认：**

- 系统只依赖商品基础资料和推广目标即可运行；
- 评论、竞品、品牌和运营资料属于增强输入；
- 缺少增强输入不能阻断基础流程；
- 系统应诚实表达资料不足；
- 输入资料采用分层管理。

**本决定尚未确认：**

- 每个字段的具体数据类型；
- 最低输入字段是否全部强制填写；
- 商品图片是否技术上必填；
- 支持哪些文件格式；
- 是否支持商品链接；
- 是否自动抓取商品页面；
- 是否自动抓取评论或竞品数据；
- 是否使用联网搜索；
- 是否将资料写入长期知识库；
- 是否使用向量数据库；
- 文档切分与检索方式；
- 输入完整度评分算法；
- 信息不足时具体向用户询问什么；
- 隐私、权限和数据保存策略。

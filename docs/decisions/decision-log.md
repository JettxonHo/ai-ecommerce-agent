# Decision Log

本文件是所有 Decision Record（DEC）的索引。每条 Accepted / Rejected / Deferred / Superseded / Amended / Deprecated 决定都应在此登记一行，便于快速检索与追踪。

> 规则：仅记录用户明确接受（或明确否决 / 暂缓）的决定。Proposed Decisions 不登记于此，保留在对应 Session 中。
> 当决定被新决定改变时，**不删除**旧行，而是在状态列标注 `Superseded` / `Amended` 并在备注中指向新 DEC。
